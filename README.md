# System Monitor

Bash-скрипт для периодического мониторинга ресурсов Linux.

## Возможности

- Сбор текущей даты и времени.
- Мониторинг uptime, RAM и дискового пространства.
- Запись результатов в monitor.log.
- Настраиваемый интервал мониторинга.
- Проверка корректности интервала.

## Использование

Запуск с интервалом 5 секунд:

```bash
./script.sh 5
```

Если интервал не указан, используется значение 5 секунд.
Для остановки необходимо нажать Ctrl+C


## Требования

Linux, Bash, утилиты uptime, free, df и sleep
